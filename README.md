# Roos Automotivo

Website institucional da **Roos Automotivo**, desenvolvido para apresentar os serviços automotivos, facilitar o contato com clientes e divulgar o atendimento a domicílio.

## Tecnologias
- HTML5
- CSS3
- JavaScript

## Funcionalidades
- Apresentação dos serviços
- Layout responsivo
- Atalho para contato via WhatsApp
- Integração com Instagram

## Acesso
Site publicado via Netlify.
https://roos-automotivo.netlify.app/
